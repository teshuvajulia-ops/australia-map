    יש שינויים שעוד לא פורסמו באתר.

    הגדרות פרסום

    כדי שהכפתור "פרסום באתר" יעדכן את האתר ישירות, צריך מפתח גישה אישי מ-GitHub. עושים את זה פעם אחת:

    1. ב-GitHub: תמונת הפרופיל, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
    2. שם: to-do-australia. תחת Repository access בחרי Only select repositories ואז australia-map.
    3. תחת Permissions, Repository permissions, בחרי Contents: Read and write.
    4. לחצי Generate token, העתיקי את המפתח (מתחיל ב-github_pat_) והדביקי כאן.
    המפתח נשמר רק בדפדפן הזה, ואף אחד אחר לא רואה אותו. אל תשלחי אותו לאף אחד.

    אירוע חדש

    מדביקים את קישור ההזמנה של הקבוצה. אם אין קבוצה, משאירים ריק והכפתור לא יופיע.
    בחרי תאריך התחלה למעלה. אפשר כמה ימים, למשל שלישי וחמישי. בלי סימון = אירוע חד פעמי.
    אירוע מקודם עולה לראש הרשימה ומסומן בבירור.
